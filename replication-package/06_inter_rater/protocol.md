# Inter-Rater Validation Protocol (Revision Template)

The original review used a single lead reviewer and did not conduct inter-rater evaluation. This file documents a possible revision-stage validation and must not be represented as part of the original protocol unless actually performed.

Suggested procedure: independently reassess a random sample of the 111 full-text reports; record Include/Exclude decisions and, if desired, QA scores; calculate observed agreement and Cohen's kappa; resolve disagreements by discussion; report the sample size and sampling method.
